Положи сюда файлы шрифтов (.ttf / .otf) — остров подхватит их сам при запуске, ставить в систему не нужно.

Material You  ->  Google Sans
  • Google Sans Flex (бесплатный, лицензия OFL): https://fonts.google.com/specimen/Google+Sans+Flex  -> Get font -> Download all
  • Либо обычный «Google Sans» / «Google Sans Text», если он у тебя есть.
  Если жирный текст выглядит не так — положи статические (не variable) .ttf.
  Нет шрифта -> берётся Roboto / Segoe UI Variable.

Apple  ->  SF Pro
  • SF Pro скачивается с developer.apple.com/fonts (шрифт Apple, лицензия не позволяет класть его в чужие проекты, поэтому его здесь нет).
  • Установи или положи SF-Pro-Text-*.otf / SF-Pro-Display-*.otf сюда.
  Нет шрифта -> берётся Inter / Segoe UI Variable.
