# Dynamic Island для Windows

Остров в стиле Apple сверху экрана: плеер (Spotify/браузер), обложка, громкость, батарея, CPU/RAM,
погода с предупреждением о дожде, быстрые приложения, уведомления. Темы: **Apple** и **Material You**
(цвета берутся из обоев, как в matugen, и плавно меняются при смене обоев).

## Сборка
Нужны Windows 10/11, Visual Studio (C++ и Windows SDK).
- `build.bat` из «Developer Command Prompt for VS», или
- CMake: `cmake -B build && cmake --build build --config Release`

Результат: `build\DynamicIsland.exe`

## Управление
- Наведи курсор — раскрывается. ПКМ по острову или иконке в трее — «Настройки» / «Выход».
- Колёсико над островом — громкость. Клик по полосе прогресса — перемотка.
- Уведомление из консоли: `DynamicIsland.exe --notify "Текст"`

## Файлы
| Файл | За что отвечает |
|---|---|
| `main.cpp` | окно, трей, меню, цикл по vsync |
| `island.cpp/.h` | состояния, наведение, клики, пружины и анимации |
| `render.cpp/.h` | отрисовка (GDI+), обновление только нужной области окна |
| `theme.cpp/.h` | темы Apple / Material You, палитра из обоев |
| `media.cpp/.h` | текущий трек, обложка, управление плеером |
| `weather.cpp/.h` | погода и дождь (Open-Meteo) |
| `sysinfo.cpp/.h` | CPU/RAM/батарея, громкость |
| `settings.cpp/.h` | настройки (реестр) и окно настроек |
| `anim.h`, `base.h`, `gdi.h` | пружины/easing, общие подключения |

## Если лагает
Настройки → «Лёгкий режим» (без теней и свечения). Рендер на GDI+ (процессор); при необходимости
можно перенести на Direct2D.
