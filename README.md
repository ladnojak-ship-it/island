# Dynamic Island для Windows

Остров в стиле Apple сверху экрана: плеер (Spotify/браузер), обложка, громкость, батарея, CPU/RAM,
погода с предупреждением о дожде, быстрые приложения, уведомления. Темы: **Apple** и **Material You**
(цвета берутся из обоев, как в matugen, и плавно меняются при смене обоев).

## Что нового (v3)
- **Автоскрытие:** когда с островом ничего не происходит (нет наведения, всплывашек, смены трека), он уезжает вверх за экран. Наведи курсор туда, где он висит, и он выпрыгивает с отскоком. Время бездействия, отступ сверху, скругление и акцентный цвет настраиваются.
- **Настоящий визуализатор (как cava):** бары показывают реальный спектр системного звука (WASAPI loopback + FFT, 16 полос). Выключается в настройках.
- **Скриншот:** когда в буфере обмена появляется картинка (Win+Shift+S, PrintScreen, «Копировать изображение»), её миниатюра летит от курсора в остров, остров на ~20 мс «раздувается» и пружинно возвращается, затем всплывашка «Скриншот в буфере обмена».
- **Исправлено:** время трека теперь считается по LastUpdatedTime плеера (раньше «зависало» у Spotify и браузеров); бегущая строка стартует с паузой только после полного раскрытия и идёт медленнее.
- **Настройки:** прокрутка колесом, акцентный цвет Material You, автоскрытие, CPU/RAM/батарея, визуализатор, анимация скриншота, скругление, отступ сверху.

## Что нового (v2)
- Крупнее и чётче текст, векторные иконки (Material Icons) вместо шрифта Segoe MDL2, обложка 256 px, рендер HighQuality.
- **Material You** — шрифт Google Sans, «волнистый» прогресс, сквиркл-кнопки; **Apple** — шрифт SF Pro и скруглённые иконки в стиле iOS. Шрифты кладутся в папку `fonts` (см. `fonts/README.txt`).
- Новое окно настроек в стиле выбранной темы (переключатели, карточки тем, палитра обоев).
- Настройка «Размер острова» 100 / 115 / 130 / 150 % (по умолчанию 115 %).

## Сборка
Нужны Windows 10/11, Visual Studio (C++ и Windows SDK).
- `build.bat` из «Developer Command Prompt for VS», или
- CMake: `cmake -B build && cmake --build build --config Release`

Результат: `build\DynamicIsland.exe`

## Управление
- Наведи курсор — раскрывается. ПКМ по острову или иконке в трее — «Настройки» / «Выход».
- Колёсико над островом — громкость. Клик по полосе прогресса — перемотка.
- Уведомление из консоли: `DynamicIsland.exe --notify "Текст"`

## Файлы
| Файл | За что отвечает |
|---|---|
| `main.cpp` | окно, трей, меню, цикл по vsync |
| `island.cpp/.h` | состояния, наведение, клики, пружины и анимации |
| `render.cpp/.h` | отрисовка (GDI+), обновление только нужной области окна |
| `theme.cpp/.h` | темы Apple / Material You, палитра из обоев |
| `media.cpp/.h` | текущий трек, обложка, управление плеером |
| `weather.cpp/.h` | погода и дождь (Open-Meteo) |
| `sysinfo.cpp/.h` | CPU/RAM/батарея, громкость |
| `settings.cpp/.h` | настройки (реестр) и окно настроек |
| `audio.cpp/.h` | захват звука и FFT для визуализатора |
| `shot.cpp/.h` | анимация скриншота (летящая миниатюра) |
| `fonts.cpp/.h` | шрифты тем, подхват из папки `fonts` |
| `icons.cpp/.h`, `icondata.h`, `svgpath.h` | векторные иконки (SVG-пути Material) |
| `gfx.h` | скруглённые прямоугольники, смешение цветов |
| `anim.h`, `base.h`, `gdi.h` | пружины/easing, общие подключения |

## Если лагает
Настройки → «Лёгкий режим» (без теней и свечения). Рендер на GDI+ (процессор); при необходимости
можно перенести на Direct2D.
